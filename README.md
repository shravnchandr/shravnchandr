## What I'm Building

### [ASL Guide](https://asl-guide.onrender.com) — Live Production App
A browser-based ASL learning platform built for real learners.

- **Live camera recognition** — TensorFlow.js classifier (95.5% accuracy) for fingerspelling and numbers via MediaPipe hand landmarks
- **100 animated signs** — MediaPipe landmark-based stick figure animations with SM-2 spaced repetition scheduling
- **AI grammar engine** — LangGraph agentic workflow applying 10 documented ASL grammar rules (TTC structure, topicalization, wh-questions, negation, classifiers)
- **Fingerspelling guide** — automatic proper noun detection with letter-by-letter hand shape breakdowns
- **PWA** — installable, works offline, mobile-friendly

Built with: FastAPI · React · TypeScript · TensorFlow.js · MediaPipe · LangGraph · Gemini API · PostgreSQL · Redis · Docker · Render
